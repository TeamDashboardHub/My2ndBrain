Politique de Confidentialité

Dernière mise à jour : 13 mai 2026

Second Brain est une application personnelle de gestion de notes et de connaissances. Nous prenons la confidentialité de vos données très au sérieux.

1. Informations que nous collectons

Second Brain est conçu pour fonctionner principalement en local sur votre appareil. Voici les données utilisées par l'application :

  • Notes personnelles — les notes que vous créez sont stockées uniquement sur votre appareil via le stockage local (localStorage). Elles ne sont jamais envoyées à nos serveurs.
  • Clé API Anthropic — si vous utilisez l'assistant IA, votre clé API est stockée localement sur votre appareil et n'est transmise qu'à Anthropic (api.anthropic.com) pour traiter vos requêtes.
  • Données Google Calendar — si vous connectez Google Calendar, un token d'accès temporaire est stocké localement. Les données de votre agenda sont récupérées directement depuis Google et affichées dans l'app, sans être stockées sur nos serveurs.

2. Comment nous utilisons vos informations

Les données collectées sont utilisées uniquement pour :

  • Afficher et gérer vos notes personnelles
  • Alimenter l'assistant IA avec le contexte de vos notes (via l'API Anthropic)
  • Afficher vos événements Google Calendar dans l'application

Nous ne vendons, ne partageons et ne transmettons jamais vos données personnelles à des tiers, sauf dans les cas décrits ci-dessus (Anthropic pour l'IA, Google pour le Calendar).

3. Stockage des données

Toutes vos notes sont stockées uniquement sur votre appareil. Si vous désinstallez l'application ou effacez les données de l'app, toutes vos notes seront supprimées définitivement.

Nous vous recommandons d'utiliser la fonction Exporter JSON régulièrement pour sauvegarder vos notes.

4. Services tiers

Second Brain utilise les services tiers suivants :

  • Anthropic (Claude API) — pour l'assistant IA. Vos messages et le contexte de vos notes sont envoyés à Anthropic pour générer des réponses. Consultez la politique de confidentialité d'Anthropic sur anthropic.com/privacy.
  • Google Calendar API — pour importer vos événements. L'accès est limité à la lecture seule de votre agenda principal. Consultez la politique de confidentialité de Google sur policies.google.com/privacy.

5. Sécurité

Nous mettons en œuvre des mesures appropriées pour protéger vos informations :

  • Les communications avec l'API Anthropic et Google sont chiffrées via HTTPS
  • Votre clé API et vos tokens d'accès sont stockés localement et ne transitent jamais par nos serveurs
  • L'application ne nécessite pas de création de compte

6. Vos droits

Vous avez le contrôle total sur vos données :

  • Accès — toutes vos notes sont visibles directement dans l'application
  • Export — vous pouvez exporter toutes vos notes en JSON à tout moment
  • Suppression — vous pouvez supprimer vos notes individuellement ou désinstaller l'app pour tout effacer
  • Révocation — vous pouvez révoquer l'accès Google Calendar depuis les paramètres de votre compte Google

7. Enfants

Second Brain n'est pas destiné aux enfants de moins de 13 ans. Nous ne collectons pas sciemment de données personnelles auprès d'enfants.

8. Modifications de cette politique

Nous pouvons mettre à jour cette politique de confidentialité occasionnellement. Nous vous informerons de tout changement en publiant la nouvelle politique sur cette page avec une date de mise à jour.
